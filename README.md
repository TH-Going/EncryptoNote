# EncryptoNote

EncryptoNote 是一个本地运行的加密富文本笔记应用。每篇笔记保存为一个 `.ecnote` 文件，打开笔记需要密码；正文、格式、工作表和粘贴进去的图片都会随笔记一起加密保存。

当前版本面向 Windows 桌面使用，界面和文档内容均为中文。

## 完全开源

EncryptoNote 的源代码、构建脚本、文档、测试和项目资源均公开在本仓库中。项目不依赖私有服务、在线授权或运行时联网校验，可以自行审阅、构建和修改。

项目自身采用 [MIT License](LICENSE)。第三方 Rust crate 和系统字体仍按各自的许可证提供。

## 当前功能

### 笔记文件

- 新建、打开和锁定 `.ecnote` 笔记。
- 新建时选择文件名、保存目录和密码；密码至少 6 个字符，并会显示强度提示。
- 同一目录下已有同名笔记时不会覆盖。
- 启动后进入“最近打开”列表，最多保留 20 条记录。
- 最近列表支持双击打开，也可以右键选择“打开”“在文件夹打开”或“从列表中移除”。
- 也可以把 `.ecnote` 文件直接拖到窗口中打开。
- 编辑器顶部提供“修改密码”和“锁定”；修改密码不会重新加密正文。
- 编辑后可以点击工具栏右侧的保存按钮，或使用 `Ctrl+S`。返回笔记库、锁定时也会尝试保存；直接关闭窗口前请先保存。

最近打开列表写入 `%APPDATA%\EncryptoNote\recent.json`，其中只保存路径、标题、文件大小和打开时间，不保存密码或密钥。

### 富文本编辑

- 段落样式：正文、标题 1/2/3、引用、代码块、项目符号、编号和分割线。
- 行内格式：粗体、斜体、下划线、删除线。
- 字号范围为 `9–72 pt`。
- 文字颜色和高亮底色。
- 左对齐、居中、右对齐、两端对齐。
- 清除选区格式。
- 每张工作表独立维护撤销/重做历史，最多保留 128 步。

### 多工作表

- 在笔记底部切换工作表，使用右侧 `＋` 新建。
- 双击标签重命名。
- 右键菜单支持复制、左移、右移、删除和设置标签颜色。
- 最多 64 张工作表，名称最多 31 个字符。

### 图片

- 使用工具栏“插入”按钮，或把图片粘贴到编辑区。
- 图片会转为 PNG，并作为笔记内容的一部分加密保存。
- 粘贴时最长边会缩放到 1600 像素以内，PNG 编码后超过 4 MiB 的图片会被拒绝。
- 选中图片后可以设置正文宽度的 25%、50%、75% 或 100%，调整左/中/右对齐，上移、下移或删除。
- 也可以拖动图片四角等比缩放，拖动左侧手柄调整图片在段落中的位置。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+L` | 锁定并返回笔记库 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+B` | 粗体 |
| `Ctrl+I` | 斜体 |
| `Ctrl+U` | 下划线 |
| `Ctrl+N` | 新建工作表 |
| `Ctrl+PageUp` / `Ctrl+PageDown` | 切换上一张/下一张工作表 |
| `Ctrl+1` … `Ctrl+5` | 切换前五张工作表 |
| `Delete` / `Backspace` | 删除选中的图片 |

## 加密与文件格式

`.ecnote` 是单文件格式，密码不直接用于加密正文，而是先派生密钥，再解包随机生成的文档密钥：

| 项目 | 当前实现 |
| --- | --- |
| 密钥派生 | Argon2id，`m=256 MiB`、`t=3`、`p=1` |
| 文档密钥 | 每个笔记随机生成 32 字节 DEK |
| 密钥包装 | XChaCha20-Poly1305，随机 24 字节 nonce |
| 文档加密 | ChaCha20-Poly1305 流式分块，每块 64 KiB |
| 完整性校验 | 每块 AEAD 认证、文档 SHA-256、文件头槽 CRC32 |
| 文件头 | 4 KiB 双槽头；保存和改密码时轮换备用槽，降低中断造成损坏的风险 |

当前版本把图片以 base64 PNG 放在加密文档 JSON 的 `images` 数组中，因此包含图片的笔记保存时会重新写入整份文档密文。文件头中的独立图片区字段为后续格式预留，当前未启用。

密码错误或文件内容被篡改时，笔记无法解锁。密钥只在解锁期间保存在内存中，锁定或退出后会清零；项目没有恢复码、服务器备份或密码找回功能。

## 当前限制

- 工具栏保存会拦截超过 1,000,000 个字符的文档。
- 序列化后的文档 JSON 上限为 8 MiB。
- 当前只能插入剪贴板图片，不提供从文件选择图片的入口。
- 没有自动锁定、云同步、协作、Markdown/PDF 导出和版本历史。
- 最近打开列表中的路径和标题会以明文保存在本机配置文件中；笔记正文仍保存在 `.ecnote` 加密文件中。
- 当前发布形态是 Windows 桌面程序；其他平台尚未作为发布目标验证。

## 直接运行

如果目录中已有 `EncryptoNote.exe`，双击即可启动。

## 从源码构建

需要 Rust 1.85+。Windows 构建建议使用 MSVC 工具链。

```powershell
cargo run
cargo build --release
```

Release 产物为：

```text
target\release\encrypto-note.exe
```

程序窗口标题为“EncryptoNote”，Cargo 包名为 `encrypto-note`。

## 开发检查

```powershell
cargo check
cargo test
```

测试覆盖文档模型、`.ecnote` 文件头、密钥派生与包装、分块加密流、保存/打开/改密码流程，以及编辑器和图片交互。

## 代码结构

```text
src/
  main.rs       程序入口、窗口配置
  app.rs        最近列表、对话框、编辑器界面和快捷键
  editor.rs     富文本排版、图片交互、撤销/重做
  model.rs      文档、工作表、段落和图片模型
  store.rs      .ecnote 的创建、解锁、保存、改密码
  crypto.rs     Argon2id、DEK 包装和密钥清零
  stream.rs     64 KiB 分块 AEAD 加解密
  format.rs     .ecnote 文件头和双槽格式
  recent.rs     最近打开列表
  ui/           字体、主题和通用控件
```

更完整的设计记录见 [`设计方案-v4-加密笔记.md`](设计方案-v4-加密笔记.md)。
